# Wavelet 数据库表设计文档

## 1. 存储引擎与全局配置

- **存储引擎**：SQLite 3（驱动：`better-sqlite3`）
- **连接初始化 PRAGMA**：
  ```sql
  PRAGMA journal_mode = WAL;
  PRAGMA synchronous = NORMAL;
  PRAGMA foreign_keys = ON;
  PRAGMA temp_store = MEMORY;
  ```

---

## 2. 数据表清单

| 表名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `tracks` | 实体表 | 音频主库表（本地唯一物理文件映射与元数据） |
| `playlists` | 实体表 | 歌单信息表 |
| `playlist_tracks` | 关联表 | 歌单与曲目多对多（M:N）收录关系及排序表 |
| `lyrics` | 扩展表 | 外置歌词与自定义时间轴偏移表 |
| `settings` | 键值表 | 播放器运行时交互偏好与状态热配置表 |
| `_schema_migrations` | 系统表 | 数据库 DDL 增量版本迁移审计表 |

---

## 3. 数据表详细设计

### 3.1 `tracks`（音频曲目主表）

| 字段名 | 类型 | 可空 | 默认值 | 约束 | 说明 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `id` | TEXT | 否 | 无 | PRIMARY KEY | 曲目唯一标识（UUIDv4） |
| `file_path` | TEXT | 否 | 无 | UNIQUE | 本地音频物理文件绝对路径 |
| `file_hash` | TEXT | 否 | 无 | UNIQUE | 音频文件 SHA-256 内容哈希（去重与重连标识） |
| `file_size` | INTEGER | 否 | 无 | CHECK(file_size > 0) | 文件物理大小（字节） |
| `title` | TEXT | 否 | 无 | 无 | 歌曲名称 |
| `artist` | TEXT | 否 | `'Unknown'` | 无 | 主要艺术家 |
| `album` | TEXT | 否 | `'Unknown'` | 无 | 专辑名称 |
| `album_artist` | TEXT | 是 | NULL | 无 | 专辑艺术家 |
| `composer` | TEXT | 是 | NULL | 无 | 作曲家 / 作词家 |
| `genre` | TEXT | 是 | NULL | 无 | 音乐流派 |
| `year` | INTEGER | 是 | NULL | 无 | 发行年份 |
| `track_number` | INTEGER | 是 | NULL | 无 | 专辑音轨序号 |
| `track_total` | INTEGER | 是 | NULL | 无 | 专辑总音轨数 |
| `disc_number` | INTEGER | 否 | `1` | 无 | 光盘编号 |
| `disc_total` | INTEGER | 否 | `1` | 无 | 总光盘数 |
| `duration` | REAL | 否 | 无 | CHECK(duration >= 0) | 音频时长（单位：秒，浮点数） |
| `bitrate` | INTEGER | 否 | 无 | CHECK(bitrate > 0) | 比特率（bps） |
| `sample_rate` | INTEGER | 否 | 无 | CHECK(sample_rate > 0) | 采样率（Hz，如 44100, 96000, 192000） |
| `bit_depth` | INTEGER | 否 | 无 | CHECK(bit_depth IN (16, 24, 32)) | 量化位深 |
| `channels` | INTEGER | 否 | `2` | CHECK(channels IN (1, 2, 6, 8)) | 声道数 |
| `format` | TEXT | 否 | `'FLAC'` | 无 | 标准化封装容器格式 |
| `original_codec` | TEXT | 否 | 无 | 无 | 原始输入编码格式（如 flac, mp3, wav, alac） |
| `has_embedded_cover` | INTEGER | 否 | `0` | CHECK(has_embedded_cover IN (0, 1)) | 是否包含内嵌封面（0=无，1=有） |
| `cover_hash` | TEXT | 是 | NULL | 无 | 封面图像 SHA-256 哈希（映射本地 WebP 缓存） |
| `has_embedded_lyrics` | INTEGER | 否 | `0` | CHECK(has_embedded_lyrics IN (0, 1)) | 是否包含内嵌歌词（0=无，1=有） |
| `health_status` | TEXT | 否 | `'healthy'` | CHECK(health_status IN ('healthy', 'repaired', 'missing')) | 健康状态（healthy=原始健康，repaired=自愈修复，missing=物理断链） |
| `repair_details` | TEXT | 是 | NULL | 无 | 自愈修复明细（JSON 格式记录缺陷类型与修复参数） |
| `play_count` | INTEGER | 否 | `0` | CHECK(play_count >= 0) | 累计播放次数（智能歌单统计源） |
| `last_played_at` | INTEGER | 是 | NULL | 无 | 最后一次播放时间戳（毫秒） |
| `created_at` | INTEGER | 否 | 无 | 无 | 曲目入库时间戳（毫秒） |
| `updated_at` | INTEGER | 否 | 无 | 无 | 元数据更新时间戳（毫秒） |

### 3.2 `playlists`（歌单与分类目录表）

| 字段名 | 类型 | 可空 | 默认值 | 约束 | 说明 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `id` | TEXT | 否 | 无 | PRIMARY KEY | 歌单唯一标识（UUIDv4） |
| `name` | TEXT | 否 | 无 | 无 | 歌单/目录名称 |
| `description` | TEXT | 是 | NULL | 无 | 歌单描述 |
| `is_default` | INTEGER | 否 | `0` | CHECK(is_default IN (0, 1)) | 是否为系统根歌单（1=全部音乐/原始歌单，不可删除；0=用户自定义歌单） |
| `parent_id` | TEXT | 是 | NULL | FOREIGN KEY -> playlists(id) ON DELETE CASCADE | 父级歌单/目录 ID，NULL 表示处于顶层根节点 |
| `is_folder` | INTEGER | 否 | `0` | CHECK(is_folder IN (0, 1)) | 是否作为纯分类目录文件夹（1=目录文件夹，0=普通歌单） |
| `cover_image_path` | TEXT | 是 | NULL | 无 | 自定义封面本地路径 |
| `track_count` | INTEGER | 否 | `0` | CHECK(track_count >= 0) | 歌单内歌曲总数（冗余统计字段） |
| `sort_order` | REAL | 否 | `0.0` | 无 | 歌单在侧边栏的排序权值 |
| `created_at` | INTEGER | 否 | 无 | 无 | 歌单创建时间戳（毫秒） |
| `updated_at` | INTEGER | 否 | 无 | 无 | 歌单更新时间戳（毫秒） |

- **索引定义**：
  - `CREATE INDEX IF NOT EXISTS idx_playlists_parent ON playlists(parent_id);` 支持 $O(1)$ 极速子目录与层级检索。

### 3.3 `playlist_tracks`（歌单-曲目多对多关联表）

| 字段名 | 类型 | 可空 | 默认值 | 约束 | 说明 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `playlist_id` | TEXT | 否 | 无 | FOREIGN KEY -> playlists(id) ON DELETE CASCADE | 关联歌单 ID |
| `track_id` | TEXT | 否 | 无 | FOREIGN KEY -> tracks(id) ON DELETE CASCADE | 关联曲目 ID |
| `sort_order` | REAL | 否 | 无 | 无 | 曲目在歌单内的排列权值（浮点数，支持无重排直接插入） |
| `added_at` | INTEGER | 否 | 无 | 无 | 加入歌单时间戳（毫秒） |

- **复合主键**：`PRIMARY KEY (playlist_id, track_id)`

---

### 3.4 `lyrics`（外置歌词与时间轴微调表）

| 字段名 | 类型 | 可空 | 默认值 | 约束 | 说明 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `track_id` | TEXT | 否 | 无 | PRIMARY KEY, FOREIGN KEY -> tracks(id) ON DELETE CASCADE | 关联曲目 ID |
| `raw_lrc` | TEXT | 否 | 无 | 无 | 包含时间戳的标准 LRC 歌词文本 |
| `offset_ms` | INTEGER | 否 | `0` | 无 | 用户手动微调的时间轴偏移量（单位：毫秒） |
| `updated_at` | INTEGER | 否 | 无 | 无 | 歌词更新时间戳（毫秒） |

---

### 3.5 `settings`（偏好与运行时热配置表）

| 字段名 | 类型 | 可空 | 默认值 | 约束 | 说明 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `key` | TEXT | 否 | 无 | PRIMARY KEY | 配置项标识键（如 `volume`, `repeat_mode`, `output_device`） |
| `value` | TEXT | 否 | 无 | 无 | 配置值（标量值或 JSON 序列化数据） |
| `updated_at` | INTEGER | 否 | 无 | 无 | 配置最后写入时间戳（毫秒） |

---

### 3.6 `_schema_migrations`（数据库版本迁移审计表）

| 字段名 | 类型 | 可空 | 默认值 | 约束 | 说明 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `version` | INTEGER | 否 | 无 | PRIMARY KEY | 迁移脚本版本号（递增正整数） |
| `name` | TEXT | 否 | 无 | 无 | 迁移脚本名称（如 `0001_initial_schema`） |
| `applied_at` | INTEGER | 否 | 无 | 无 | 迁移执行完成时间戳（毫秒） |

## 4. 索引设计

| 索引名称 | 目标表 | 索引字段 | 作用场景 |
| :--- | :--- | :--- | :--- |
| `idx_tracks_search` | `tracks` | `(title, artist, album)` | 本地曲库三字段即时复合模糊检索 |
| `idx_tracks_health` | `tracks` | `(health_status)` | 异常断链曲目过滤与自愈曲目视图 |
| `idx_tracks_play_stats` | `tracks` | `(play_count DESC, last_played_at DESC)` | 最常收听与最近播放智能歌单排序 |
| `idx_playlist_tracks_order` | `playlist_tracks` | `(playlist_id, sort_order)` | 歌单曲目序列按权值顺序读取 |
| `idx_playlists_sort` | `playlists` | `(sort_order)` | 侧边栏歌单目录树自定义排列 |

---

## 5. 完整 DDL 脚本

```sql
-- 启用 WAL 模式与外键约束
PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
PRAGMA foreign_keys = ON;
PRAGMA temp_store = MEMORY;

-- 1. 迁移版本表
CREATE TABLE IF NOT EXISTS _schema_migrations (
    version INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    applied_at INTEGER NOT NULL
);

-- 2. 曲目主表
CREATE TABLE IF NOT EXISTS tracks (
    id TEXT PRIMARY KEY,
    file_path TEXT NOT NULL UNIQUE,
    file_hash TEXT NOT NULL UNIQUE,
    file_size INTEGER NOT NULL CHECK(file_size > 0),
    title TEXT NOT NULL,
    artist TEXT NOT NULL DEFAULT 'Unknown',
    album TEXT NOT NULL DEFAULT 'Unknown',
    album_artist TEXT,
    composer TEXT,
    genre TEXT,
    year INTEGER,
    track_number INTEGER,
    track_total INTEGER,
    disc_number INTEGER NOT NULL DEFAULT 1,
    disc_total INTEGER NOT NULL DEFAULT 1,
    duration REAL NOT NULL CHECK(duration >= 0),
    bitrate INTEGER NOT NULL CHECK(bitrate > 0),
    sample_rate INTEGER NOT NULL CHECK(sample_rate > 0),
    bit_depth INTEGER NOT NULL CHECK(bit_depth IN (16, 24, 32)),
    channels INTEGER NOT NULL DEFAULT 2 CHECK(channels IN (1, 2, 6, 8)),
    format TEXT NOT NULL DEFAULT 'FLAC',
    original_codec TEXT NOT NULL,
    has_embedded_cover INTEGER NOT NULL DEFAULT 0 CHECK(has_embedded_cover IN (0, 1)),
    cover_hash TEXT,
    has_embedded_lyrics INTEGER NOT NULL DEFAULT 0 CHECK(has_embedded_lyrics IN (0, 1)),
    health_status TEXT NOT NULL DEFAULT 'healthy' CHECK(health_status IN ('healthy', 'repaired', 'missing')),
    repair_details TEXT,
    play_count INTEGER NOT NULL DEFAULT 0 CHECK(play_count >= 0),
    last_played_at INTEGER,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL
);

-- 3. 歌单表
CREATE TABLE IF NOT EXISTS playlists (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,
    is_default INTEGER NOT NULL DEFAULT 0 CHECK(is_default IN (0, 1)),
    cover_image_path TEXT,
    track_count INTEGER NOT NULL DEFAULT 0 CHECK(track_count >= 0),
    sort_order REAL NOT NULL DEFAULT 0.0,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL
);

-- 4. 歌单-曲目多对多关联表
CREATE TABLE IF NOT EXISTS playlist_tracks (
    playlist_id TEXT NOT NULL,
    track_id TEXT NOT NULL,
    sort_order REAL NOT NULL,
    added_at INTEGER NOT NULL,
    PRIMARY KEY (playlist_id, track_id),
    FOREIGN KEY (playlist_id) REFERENCES playlists(id) ON DELETE CASCADE,
    FOREIGN KEY (track_id) REFERENCES tracks(id) ON DELETE CASCADE
);

-- 5. 歌词表
CREATE TABLE IF NOT EXISTS lyrics (
    track_id TEXT PRIMARY KEY,
    raw_lrc TEXT NOT NULL,
    offset_ms INTEGER NOT NULL DEFAULT 0,
    updated_at INTEGER NOT NULL,
    FOREIGN KEY (track_id) REFERENCES tracks(id) ON DELETE CASCADE
);

-- 6. 偏好与运行时热配置表
CREATE TABLE IF NOT EXISTS settings (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    updated_at INTEGER NOT NULL
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_tracks_search ON tracks(title, artist, album);
CREATE INDEX IF NOT EXISTS idx_tracks_health ON tracks(health_status);
CREATE INDEX IF NOT EXISTS idx_tracks_play_stats ON tracks(play_count DESC, last_played_at DESC);
CREATE INDEX IF NOT EXISTS idx_playlist_tracks_order ON playlist_tracks(playlist_id, sort_order);
CREATE INDEX IF NOT EXISTS idx_playlists_sort ON playlists(sort_order);
```

## 6. 核心实体关系与级联规则

```
+---------------+          1:N          +-------------------+          N:1          +---------------+
|   playlists   | --------------------< |  playlist_tracks  | >-------------------- |    tracks     |
+---------------+                       +-------------------+                       +---------------+
        |                                                                                   |
        | (is_default = 1: 系统根歌单)                                                      | 1:1
        v                                                                                   v
(不可物理删除)                                                                         +---------------+
                                                                                        |    lyrics     |
                                                                                        +---------------+
```

- **歌单解绑**：从普通歌单删除曲目时，仅删除 `playlist_tracks` 对应行，不影响 `tracks` 物理实体与其它歌单。
- **曲目彻底删除**：仅在根歌单（`is_default = 1`）触发删除时，级联清除所有关联歌单引用（`playlist_tracks`）、歌词（`lyrics`），并物理删除磁盘对应 FLAC 文件与无引用封面。
