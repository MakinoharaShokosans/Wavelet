# Wavelet - 项目概要

## 1. 项目定位

Wavelet 是一款本地音乐播放与音频管理软件，采用 **Web 前端交互（React + TypeScript）+ 独立本地服务引擎（Node.js + Fastify + SQLite）** 架构。

### 核心特性
- **全链路 TypeScript**：前端 SPA 与本地后端引擎共享类型契约，统一开发与运行标准。
- **发烧级底层直通（Bit-Perfect）**：后端可直连硬件音频接口（Linux ALSA Direct / Windows WASAPI Exclusive），绕过操作系统混音器的强制有损重采样（SRC）；同时支持本地 HTTP Range Web 流式播放。
- **音频体检与智能自愈**：二进制流级检测格式伪装、文件尾部截断、头信息缺失、CRC/MD5 异常等缺陷，自动抢救并标准化转码为无损 FLAC。
- **纯白几何设计语言**：以纯白（#FFFFFF）与浅灰层次为基底，结合三次贝塞尔流体频谱曲线与无彩色微质感交互。
- **本地优先与隐私安全**：单用户本地回环（127.0.0.1）运行，数据与物理文件全部保存在本地，零外网服务依赖。

## 2. 系统技术架构

```
+-------------------------------------------------------------------------+
|                              Wavelet Web UI                             |
|               (React 19 + Vite + Tailwind CSS + Zustand)                |
+------------------------------------+------------------------------------+
                                     | Localhost IPC (REST + WebSocket 60fps)
+------------------------------------+------------------------------------+
|                         Wavelet Backend Engine                          |
|                     (Node.js LTS + TypeScript)                          |
|                                                                         |
|  [Fastify 网关]     [SQLite 存储引擎]    [体检自愈流水线]     [声卡直通]    |
|  (REST / WS / Range) (better-sqlite3)   (Worker 线程池转码)  (ALSA/WASAPI)|
+------------------------------------+------------------------------------+
                                     | 本地 IO / 驱动
+------------------------------------+------------------------------------+
|        本地存储 (~/.wavelet)        |        物理声卡 (Bit-Perfect)       |
+------------------------------------+------------------------------------+
```

## 3. 技术栈一览

| 分层 / 领域 | 核心选型 | 作用说明 |
| :--- | :--- | :--- |
| **前端交互层** | React 19 + TypeScript + Vite | 现代化 Web SPA 交互界面与工程构建 |
| **样式与视觉** | Tailwind CSS + Lucide Icons | 纯白极简布局、无彩色微质感与几何组件 |
| **动态频谱与波形** | 原生 Canvas 2D + Bézier 插值 | 接收 64 维频域数据并绘制平滑流体音波 |
| **前端状态管理** | Zustand | 播放时钟、队列、歌单树响应式状态中枢 |
| **前后端通信** | Fastify REST + WebSocket (`ws`) | 本地 API 控制、60fps 实时频谱流与播放时钟对齐 |
| **本地后端核心** | Node.js (v20+ LTS) + TypeScript | 本地守护式服务，负责 IO、转码调度与驱动控制 |
| **本地持久化** | SQLite 3 (`better-sqlite3`) | 单文件嵌入式存储，WAL 模式，支持 M:N 多歌单引用 |
| **格式嗅探与打标** | `file-type` + `music-metadata` | 二进制魔数精准识别、多格式元数据与封面提取 |
| **转码与封装** | `ffmpeg-static` + `fluent-ffmpeg` | Worker 线程池并发无损转码为标准化 FLAC |
| **硬件音频输出** | `node-speaker` / `audify` | 底层声卡独占输出，还原无损母带精度 |

## 4. 支持格式规格

| 分类 | 格式扩展名 | 处理机制与定位 |
| :--- | :--- | :--- |
| **核心推荐格式** | `.flac` | 标准化存储与母带级无损直通格式，支持 Vorbis 注释与内嵌封面歌词 |
| **无损格式兼容** | `.wav`, `.alac`, `.aiff`, `.ape` | 无损解析，保持原采样率与位深标准化转码封装为 FLAC |
| **主流有损格式** | `.mp3`, `.aac`, `.m4a`, `.ogg`, `.opus`, `.wma` | 高保真解码并统一转码封装为 FLAC 容器归档，标记原编码 |
| **现代 Web 格式** | `.webm` | 解复用后提取音频流并标准化封装 |
| **歌词文件** | `.lrc` | 支持外部 LRC 自动关联与 FLAC 内嵌 Vorbis `LYRICS` 读写 |
| **播放列表** | `.m3u`, `.m3u8` | UTF-8 标准本地播放列表双向导入导出 |

## 5. 核心功能模块

### 5.1 播放主控与流体可视化
- **播放控制**：播放/暂停、精准 Seek、列表循环/单曲循环/随机播放、对数音量调节与微淡入淡出防爆音。
- **双模回放**：优先底层声卡独占直出（Bit-Perfect）；支持本地 HTTP Range 供浏览器 Web Audio 兼容回放。
- **流体频谱**：后端 FFT 提取 64 维能量点，WebSocket 60fps 推送，前端 Canvas 拟合平滑贝塞尔曲线。
- **沉浸歌词**：毫秒级时序垂直居中平滑滚动、双语对照、点击歌词行直接 Seek。

### 5.2 资产管理与多歌单系统
- **物理与逻辑解耦**：物理文件在曲库目录单份存储，歌单通过 SQLite `playlist_tracks` 建立 M:N 关联。
- **默认全库歌单**：所有入库曲目自动汇入系统根歌单（不可删除）。
- **歌单操作**：支持自定义歌单创建、排序权值拖拽、批量加入与 `.m3u` 导入导出。
- **智能歌单**：动态视图展示最近播放、最常收听与 Hi-Res 母带专区。

### 5.3 音频体检与自愈流水线
- **魔数防伪**：根据二进制头字节识别真实格式，纠正扩展名伪装。
- **分级自愈**：针对头信息损坏、尾部截断、STREAMINFO 丢失、RIFF 大小错误等场景自动重构修复。
- **隔离归档**：不可逆严重损坏文件放入隔离区并生成诊断日志，杜绝脏数据入库。

### 5.4 可视化元信息与歌词编辑
- **元数据编辑**：可视化修改曲名、艺术家、专辑、流派、年份、音轨号，无损原地回写 FLAC 头部。
- **封面管理**：支持拖拽替换、裁剪、原图导出与 WebP 缓存生成。
- **波形辅助打轴**：结合音频波形走带，支持快捷键即时打轴与时间轴锚点拖拽微调。

### 5.5 系统容灾与健壮性
- **断链重连**：外部移动或改名时保留逻辑歌单与播放历史，标记失联状态并支持哈希自动重连。
- **级联删除**：仅在根歌单彻底删除时触发物理文件清理与孤立封面缓存垃圾回收。
