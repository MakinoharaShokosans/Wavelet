## 1. 运行时配置架构 (`src/config/index.ts`)

Wavelet 前端配置采用**静态缺省值驱动 + 环境变量覆写 + 智能自适应推导**的单例架构：

```typescript
export interface WaveletFrontendConfig {
  /** REST API 根地址 (开发环境下由 Vite 代理直接使用当前 Origin) */
  apiBaseUrl: string;
  /** WebSocket 实时长连接端点 */
  wsBaseUrl: string;
  /** 默认启动音量 (0.0 ~ 1.0) */
  defaultVolume: number;
  /** 整轨归一化波形峰值采样点数 */
  waveformSamplePoints: number;
  /** 实时频域可视化 FFT 频段分析维度 */
  fftBandsCount: number;
  /** WebSocket 心跳保活探测周期 (毫秒) */
  wsHeartbeatIntervalMs: number;
  /** WebSocket 断线重连最大退避等待时间 (毫秒) */
  wsMaxReconnectDelayMs: number;
  /** 悬浮气泡卡片防抖延迟 (毫秒) */
  hoverDebounceMs: number;
}
```

### 参数基线配置表
| 配置项 | 默认基线值 | 调控目的与技术原理 |
| :--- | :--- | :--- |
| `apiBaseUrl` | `''` (同源) | 本地构建产物由后端 `@fastify/static` 单端口提供服务；开发环境通过 `vite.config.ts` 代理。 |
| `wsBaseUrl` | `ws://${location.host}/ws/live` | 自动匹配当前浏览器的协议（`ws://` 或 `wss://`），直连后端 60fps 实时广播中枢。 |
| `defaultVolume` | `0.75` | 保证首次点播音量温和，防止发烧级直通输出产生冲击。 |
| `waveformSamplePoints` | `128` | 整轨 128 点归一化浮点峰值数组，在轻量内存（$\approx 1\text{KB}$）与视网膜高密度展示间取得最优平衡。 |
| `fftBandsCount` | `64` | 64 维对数加权能量频段，完美对应低频、人声与高频泛音，作为 60fps Canvas 贝塞尔曲线控制点。 |
| `wsHeartbeatIntervalMs`| `30000` (30s) | 维持长连接活跃状态，穿透中间反向代理连接超时限制。 |
| `wsMaxReconnectDelayMs`| `10000` (10s) | 指数退避重连封顶上限，避免服务短时重启时对网关产生雪崩冲击。 |
| `hoverDebounceMs` | `120` (120ms) | 防止鼠标掠过 UI 时频繁弹出生硬气泡，提供如丝般凝滞呼吸感。 |

## 2. 强类型分层字典 (`src/types/`)

前端类型字典严格按照**领域模型继承（Shared Domain）**与**UI 交互展示专用（Presentation UI）**进行正交解耦。

### 2.1 顶层视图路由状态模型 (`src/types/view.ts`)
```typescript
/**
 * 全局单页顶层工作流视图状态
 */
export type AppView = 
  | 'splash'          // 启动阶段：5 组艺术音符跳跃与数据看板沉降
  | 'zero'            // 零曲目冷启动：纯字悬浮导入浮岛
  | 'carousel'        // 首页大厅：一级歌单横向中心吸附轮播舞台
  | 'playlist-detail' // 歌单内部：互斥双模展示 (文件夹轮播 vs 曲目列表)
  | 'player-stage';   // 沉浸播放大舞台：黑胶唱盘 + 60fps 贝塞尔流体音波 + 歌词

/**
 * 实体歌单内部双模展示形态
 */
export type PlaylistViewMode = 'cards' | 'list';

/**
 * 面包屑导航项
 */
export interface BreadcrumbItem {
  id: string;
  name: string;
  isFolder: boolean;
}
```

### 2.4 零 `any` 规则守则
1. 所有组件必须使用 `React.FC<P>` 或明确标注返回值 `React.JSX.Element`。
2. 任何来自 REST API 或 WebSocket 的载荷数据，必须经过类型安全断言与强类型声明，**严禁使用 `any` 或逃逸类型 `unknown as any`**。
3. 共享领域类型统一从 `@wavelet/shared` 导入（如 `Track`, `Playlist`, `WaveformData`, `LibraryStats`, `PlayMode`）。
