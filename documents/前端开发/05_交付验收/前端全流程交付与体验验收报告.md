## 3. 核心体验与关键业务特性验收

### 3.1 5 视图有限状态机 (FSM) 无缝转场闭环
应用采用显式 `currentView` 状态机编排，消除了传统 URL 路由在极简桌面端应用中的突兀闪烁：
```
                  ┌──────────────┐
                  │  SplashView  │ (5 音符动画 + 预热数据看板)
                  └──────┬───────┘
                         │
           ┌─────────────┴─────────────┐
           ▼ (曲库 trackCount == 0)     ▼ (曲库 trackCount > 0)
    ┌──────────────┐            ┌──────────────┐
    │ZeroStateView │            │CarouselStage │ (根歌单中心吸附轮播)
    └──────────────┘            └──────┬───────┘
                                       │ 点击卡片
                                       ▼
                               ┌───────────────────┐
                               │PlaylistDetailView │ (分类下钻 / 双模视图)
                               └───────┬───────────┘
                                       │ 点击底部 Dock
                                       ▼
                               ┌──────────────┐
                               │ PlayerStage  │ (黑胶 + 60fps 音波 + 实时歌词)
                               └──────────────┘
```

### 3.2 歌单与歌曲层级严格互斥原则 (Mutual Exclusion)
* **分类目录文件夹 (`isFolder: true`)**：
  * 只展示子歌单或下级分类目录轮播轨道 (`SubPlaylistCarousel`)。
  * 顶部显式展示“分类目录”徽章，杜绝挂载单曲，无“播放全部”或“单曲列表”形态。
* **实体歌单 (`isFolder: false`)**：
  * 支持一键“播放全部”与“随机播放”。
  * 提供双模态展示切换：极简无边框单曲列表 (`TrackListView`) 与 封面卡片横向轮播 (`TrackCarouselView`)。
  * 面包屑导航支持任意层级目录递归回退，历史记录自动裁剪。

### 3.3 发烧级播放舞台 (PlayerStage) 与 60fps 物理引擎
* **几何黑胶唱片 (`VinylRecord`)**：
  * 播放状态下以 3s/圈 速度做无限匀速 360° 旋转，暂停时自然平滑停驻。
  * 唱针臂带物理折角，播放时以右上方为支点顺滑下压 24°，暂停时回弹抬起。
* **60fps 贝塞尔波浪流体音波 (`FluidWaveform`)**：
  * 原生 HTML5 Canvas 绘制，双重贝塞尔三次曲线（实相波与滞后波叠加）。
  * 振幅由音频播放状态与实时音量自适应加权，零卡顿、零内存泄漏。
* **双轨同步 LRC 歌词 (`LyricsPanel`)**：
  * 毫秒级解析 LRC 时间轴，当前行高亮放大放大至 105% 并平滑滚动居中。
  * 每一行均支持无障碍点击或键盘回车交互，直接触发 `playerStore.seek(timeMs)`。

### 3.4 交互细节与无障碍支持 (Micro-Interactions & a11y)
* **悬浮卡片防抖提示 (`FloatingCard`)**：
  * 120ms 防抖，鼠标快速掠过不触发抖动渲染，鼠标移入以微弹性弹出。
* **全局无边框列表条目 (`TrackListItem`)**：
  * 常态下保持克制留白，鼠标悬浮平滑浮出“心动收藏 / 加入队列 / 从歌单移出”操作小岛。
  * 严格拆分单曲点击与操作按钮，杜绝嵌套交互，完整支持键盘 Space / Enter 播放。
* **全局空格控制快捷键**：
  * 智能检测焦点元素，在非输入框状态下按空格键即刻播放/暂停，不阻断文本编辑。
